# familyplanner

A private family organizer for iOS: shared tasks, occasions (birthdays with gift ideas and to-dos), a kanban board and roles for different family members.

Hobby project, also a testbed for an automated, agent-assisted development pipeline. Not intended for the App Store; distributed to family via TestFlight.

Status: just started. See `CLAUDE.md` for the working rules.

All data in this repository is fictional.
